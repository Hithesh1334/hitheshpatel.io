The short version

Most of my work starts the same way: a data system that's brittle, tangled, or quietly wrong. The rebuild is my job.

For 2+ years at phData, I've modernized financial data ecosystems for enterprise clients: secure, production-grade pipelines on dbt, Snowflake, and Airflow.

Lately I've been wiring LLM agents and custom MCP tooling into our engineering workflows: collapsing multi-day investigations into a single prompt, without handing anyone the keys to a black box.

I care about three things: code the next person can read, flagging problems early, and owning what I ship after it goes live.

Prism: Building Data Pipelines End to End with AI
React 19TypeScriptViteTailwindFastAPIPythonLangChainLangGraphMCPWebSocketsSQLite
  • A tool where the canvas is the pipeline — ingestion → transformation → dashboard, each node a real stage of data engineering. Transformation is built end to end; the other two are scaffolded.

  • Skills: reusable instruction blocks injected into the system prompt, suggested by keyword match as you type.
